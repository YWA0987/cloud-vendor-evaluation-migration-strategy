# One-slide executive decision summary

The original presentation slide emphasized:

**Recommendation:** Microsoft Azure for the fictional 25-store Lakefront Retail, subject to validation.

**Three-year modeled economic cost (October 2026):**

| Provider | Total |
|:--|--:|
| Azure | $243,741 |
| Google Cloud | $333,382 |
| AWS | $423,343 |

**Why Azure?** The lowest modeled cost and fit with the small team's Microsoft experience.

**Main risk:** Software compatibility could raise costs or delay the transition; test before making purchases.

**Timing:** Target cutover by month eight and leave one month before lease expiration.

*All totals include cloud services, transition expenses, and internal staff time. They exclude contingency and possible exit expenses. The selected configurations are not identical.*
